I'll explain how to use the Smart Billing System step by step:

1. Prepare QR Codes/Barcodes
   
   - Generate QR codes for the test products using any online QR code generator
   - Create QR codes for these sample barcodes:
     - 8901234567890 (Milk)
     - 8902345678901 (Bread)
     - 8903456789012 (Eggs)
     - 8904567890123 (Butter)
     - 8905678901234 (Cheese)
   - Print or display them on another device
2. Start the Application
3. Using the System :
   
   - The left panel shows your webcam feed
   - Hold the QR code in front of your camera
   - Keep it steady and about 6-12 inches from the camera
   - When detected:
     - A green rectangle will appear around the QR code
     - You'll hear a beep sound
     - The item will appear in the billing table
4. Alternative Manual Entry :
   
   - If scanning doesn't work, use the "Manual Barcode Entry" field
   - Type any of the sample barcodes (e.g., 8901234567890)
   - Click "Add" or press Enter
5. Managing the Bill :
   
   - Items automatically add to the billing table
   - Quantities auto-update if you scan the same item multiple times
   - Total amount updates automatically
   - Use "Clear" button to start over
   - Click "Generate Bill" to create a PDF receipt
6. Best Practices for Scanning :
   
   - Ensure good lighting
   - Hold the QR code steady
   - Avoid glare on the QR code
   - Keep the QR code flat (not bent)
   - Make sure the entire QR code is visible in the camera
7. Viewing Results :
   
   - Generated bills save in the same folder as your script
   - Filename format: bill_YYYYMMDD_HHMMSS.pdf
   - Check the total amount display for verification
